# Proposals

Concrete solutions worth debating. Unlike the [`problems/`](../problems/) folders (which describe *what's wrong*), each proposal here argues for a *specific intervention* — and is held to the same discipline:

**Idea stated fairly → honest case for it → strongest objections → improved/alternative versions → what we'd measure.**

A proposal with no real "Objections" section is incomplete. The point is not to win; it's to find the version that survives.
